# Банковские операции
Проект представляет собой консольное приложение на Python, которое анализирует данные о банковских операциях клиента и выводит на экран список **5 последних выполненных операций** в удобочитаемом формате.

## Функциональность:

Приложение выполняет следующие задачи:

- загружает список банковских операций клиента
- фильтрует только **выполненные (EXECUTED)** операции
- сортирует операции по дате (от новых к старым)
- выводит **5 последних операций** в формате:

<дата перевода> <описание перевода> <откуда> -> <куда> <сумма перевода> <валюта>

Пример вывода:

14.10.2018 Перевод организации Mastercard 1596837868705199 -> Счет **9638 82771.72 руб.

## Запуск проекта

### 1. Клонируйте репозиторий:
```bash
git clone https://github.com/G-Ilkhom/bank_operations.git
cd bank_operations
```

### 2. Убедитесь, что установлен Python версии 3.8 или выше:
```bash
python --version
```

### 3. Запустите приложение:
```bash
python src/main.py
```
